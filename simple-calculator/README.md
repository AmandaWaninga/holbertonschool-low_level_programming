 0x00. C - Simple Calculator

 Description
An introductory C programming project covering loops and scanf for user inputs, cacluations and user output.

 Requirements
 **OS:** Ubuntu 20.04 LTS
 **Compiler:** `gcc -Wall -Werror -Wextra -pedantic -std=gnu89`
 **Style:** Checked with `betty-style.pl` and `betty-doc.pl`

Files
 `calculator.c` - Runs a C file through the preprocessor and saves the result into another file.

 Usage

gcc -Wall -Werror -Wextra -pedantic -std=gnu89 4-puts.c -o puts_example
./calculator.c
